# 🤖 Automation Research

## 📚 Checkpoint 2 - Research: The Language of Automation

### 🖥️ 1. Bash Script
A Bash script is a file containing multiple Linux commands that can be executed together to automate tasks. The `#!/bin/bash` line, called the shebang, tells the system to use the Bash interpreter to run the script.

### 📦 2. Variables
Variables are used to store values such as folder paths, filenames, or other information that can be reused in a script. Using variables like `$BACKUP_DIR` makes scripts easier to maintain because changing one variable can update the value used throughout the script.

### ⏰ 3. Cron Job
A cron job is a scheduled task in Linux that automatically runs commands or scripts at a specific time or interval. It is essential for cloud operations because it helps automate repetitive tasks like backups, system maintenance, and monitoring without requiring manual execution.

## 🎯 Key Takeaway
Bash scripts, variables, and cron jobs help cloud engineers automate repetitive tasks, improve efficiency, and maintain reliable server operations.
