# 📝 Checkpoint 7 - Mission Reflection

This laboratory helped me understand how Docker Compose makes cloud deployment easier and more organized. Writing a `docker-compose.yml` file allows a cloud engineer to define the configuration of multiple containers in one place. Instead of manually typing many commands, the engineer can use a single command to start the entire application. This saves time, reduces mistakes, and makes the deployment process easier to repeat.

I also learned that YAML indentation is very important. If I accidentally use a Tab instead of spaces or place a line at the wrong indentation level, Docker Compose may show an error and fail to read the configuration file. This experience taught me to check the structure and formatting of my code carefully.

Environment variables, such as `MYSQL_PASSWORD`, are used to configure services and provide the information needed for the application and database to communicate. They make configuration easier to manage because values can be changed without modifying the application's main code. However, sensitive passwords should be protected and not shared publicly.

Deploying Nextcloud with MariaDB in just a few minutes felt exciting because I was able to see how different containers work together as one system. At first, I encountered YAML errors, but fixing them helped me understand the configuration better. I felt more confident after learning how to check the status of the containers and verify the deployment.

Since Mission 1, my understanding of cloud computing has improved. I now understand that cloud computing involves more than storing files or running a server. It also includes managing containers, connecting services, configuring applications, and automating deployment. This mission helped me develop practical skills that I can use in future cloud computing activities and in my career in Information Technology.
