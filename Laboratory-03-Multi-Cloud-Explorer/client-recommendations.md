# ☁️ Client Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: AWS

I recommend **Amazon Web Services (AWS)** for the startup company because it provides flexible and scalable cloud services. The company can start with only the resources it needs, which can help manage its limited budget. As the mobile application gains more users, AWS can scale its infrastructure to handle the increasing demand. AWS also provides a wide range of services that can support the startup as it grows.

### Recommended Services

* **Amazon EC2** – for running the application's servers.
* **Amazon S3** – for storing files, images, and application data.
* **AWS Lambda** – for running serverless functions without managing servers.
* **Amazon RDS** – for managing the application's database.

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

I recommend **Microsoft Azure** because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure has strong integration with Microsoft technologies, making it easier for the university to connect its existing systems with cloud services. The university can also use Microsoft Entra ID to manage identities and access in a cloud environment. This makes Azure a practical choice for gradually migrating university services to the cloud.

### Recommended Services

* **Azure Virtual Machines** – for hosting Windows Server workloads.
* **Microsoft Entra ID** – for identity and access management.
* **Azure Blob Storage** – for storing university files and data.
* **Azure Virtual Network** – for securely connecting cloud resources.

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

I recommend **Google Cloud Platform (GCP)** because it is strong in Artificial Intelligence, Machine Learning, and data analytics. Google Cloud provides specialized tools and services that can help researchers develop, train, and deploy AI models. It also offers high-performance computing resources for workloads that require powerful processing. This makes GCP a suitable choice for an organization focused on AI and Machine Learning research.

### Recommended Services

* **Vertex AI** – for building, training, and deploying machine learning models.
* **Compute Engine** – for running high-performance virtual machines.
* **Google Kubernetes Engine (GKE)** – for deploying and managing containerized AI applications.
* **Cloud Storage** – for storing datasets and research files.

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

I recommend **Amazon Web Services (AWS)** because the company serves customers around the world and requires highly available infrastructure. AWS has a large global infrastructure with multiple Regions and Availability Zones that can help support reliable worldwide applications. Services such as Auto Scaling can automatically adjust resources based on customer demand, especially during busy shopping periods. AWS can also provide global content delivery and load balancing to improve application performance and availability.

### Recommended Services

* **Amazon EC2 Auto Scaling** – for automatically increasing or decreasing computing resources.
* **Elastic Load Balancing (ELB)** – for distributing customer traffic across multiple servers.
* **Amazon CloudFront** – for delivering website content quickly to customers worldwide.
* **Amazon RDS** – for managing highly available relational databases.
