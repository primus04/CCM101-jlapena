# 🔷 Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, databases, networking, analytics, artificial intelligence, containers, security, and application development. Organizations can use Azure to build, deploy, and manage applications and infrastructure through Microsoft's cloud platform (Microsoft, n.d.).

## 2. Global Infrastructure

Azure has a large global infrastructure made up of geographic regions, datacenters, and Availability Zones. Microsoft currently describes Azure as having **80+ regions and 500+ datacenters**. Azure geographies contain one or more regions and are designed to help organizations meet requirements such as data residency, compliance, availability, and low latency (Microsoft, 2026a, 2026b).

Azure Availability Zones are physically and logically separated datacenters with independent power, networking, and cooling. They are connected by low-latency networking and can be used to improve application resiliency and availability (Microsoft, 2026c).

## 3. Cloud Management Console

The **Azure portal** is a web-based, unified management console for creating, managing, and monitoring Azure resources. It provides a graphical interface for services such as virtual machines, databases, applications, subscriptions, and cost monitoring. Users can also customize dashboards and use search and guided tools to manage resources (Microsoft, 2026d).

## 4. Four Core Services

### 4.1 Azure Virtual Machines

Azure Virtual Machines provide scalable Windows and Linux virtual machines. They can be used for web servers, business applications, databases, high-performance computing, and other workloads (Microsoft, n.d.-a).

### 4.2 Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service for storing large amounts of unstructured data such as documents, images, videos, backups, and application data (Microsoft, n.d.-b).

### 4.3 Azure SQL Database

Azure SQL Database is a fully managed relational database service based on the SQL Server engine. Microsoft manages tasks such as patching, backups, availability, and monitoring, allowing organizations to focus on their applications and data (Microsoft, n.d.-c).

### 4.4 Azure Functions

Azure Functions is a serverless computing service used to run event-driven code without managing servers. It is useful for APIs, automation, background processing, and applications that respond to events (Microsoft, n.d.-d).

## 5. Three Advantages

1. **Strong enterprise integration** – Azure works closely with Microsoft technologies and enterprise environments.
2. **Global infrastructure** – Its many regions and datacenters support worldwide deployment, low latency, and data residency requirements.
3. **Managed services** – Services such as Azure SQL Database and Azure Functions reduce the amount of infrastructure administration required.

## 6. Typical Enterprise Use Cases

- Hosting Windows and Linux business applications.
- Migrating existing enterprise systems to the cloud.
- Running databases and business information systems.
- Building APIs and serverless applications.
- Containerized application deployment using Azure Kubernetes Service.
- Data analytics, AI, backup, and disaster recovery.
- Hybrid cloud and Microsoft enterprise integration.
