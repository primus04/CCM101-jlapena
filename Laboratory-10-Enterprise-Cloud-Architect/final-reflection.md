# 📝 Final Reflection
## CCM101 – Cloud Computing | Laboratory 1–10
### ☁️ CloudNova Technologies

Completing Laboratories 1–10 in CCM101 – Cloud Computing was a valuable learning experience that helped me understand how cloud infrastructure works and how it can be managed in real-world situations. Throughout these laboratories, I gradually developed my knowledge of Linux, cloud computing, virtualization, networking, storage, containerization, security, and automation.

During the first laboratories, I learned the basic concepts of cloud computing, Linux commands, and infrastructure planning. I became more familiar with using Ubuntu, checking system resources, understanding server configurations, and documenting infrastructure using Markdown and GitHub. These activities helped me build a strong foundation before moving to more advanced cloud engineering tasks.

As the laboratories progressed, I gained practical experience in deploying and managing applications using Docker. I learned how to use Docker containers, Docker Compose, and persistent storage to create connected services such as WordPress and MariaDB. I also experienced the importance of monitoring server resources, checking application logs, and troubleshooting problems to maintain system performance and reliability.

Security and automation were also important parts of my learning journey. I learned how to configure firewalls, secure SSH access, limit unnecessary network connections, and protect sensitive information. Through Bash scripting and Cron, I discovered how repetitive tasks such as database backups can be automated to improve efficiency and reduce manual work.

The final Enterprise Cloud Architect laboratory allowed me to combine the skills I learned throughout the course into one complete cloud infrastructure project called CloudNova. It demonstrated how virtualization, networking, containers, security, storage, and automation work together to support a functional web application.

Overall, CCM101 helped me improve my technical knowledge, problem-solving skills, and confidence in working with cloud technologies. Some activities were challenging, especially troubleshooting errors and understanding configurations, but these experiences helped me become more patient and independent in solving technical problems. This course taught me that cloud computing is not only about deploying applications but also about maintaining secure, reliable, and efficient infrastructure. The knowledge and experience I gained from Laboratories 1–10 will be useful in my future studies and career as an IT professional.
