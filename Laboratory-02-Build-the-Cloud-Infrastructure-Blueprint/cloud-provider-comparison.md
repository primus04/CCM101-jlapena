# Cloud Provider Comparison

This assessment compares the three major cloud providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Each provider has different service names, but they provide similar services for the main areas of cloud infrastructure.

The information was gathered from the official documentation of AWS, Microsoft Azure, and Google Cloud.

---

## Infrastructure Service Comparison

| **Infrastructure Component** | **Amazon Web Services (AWS)** | **Microsoft Azure** | **Google Cloud Platform (GCP)** |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Azure RBAC | Google Cloud IAM |

### 🖥️ Compute

Amazon EC2, Azure Virtual Machines, and Google Compute Engine provide virtual computers that can run applications, programs, and other workloads. They give organizations computing power without needing to maintain physical servers.

### 💾 Storage

Amazon S3, Azure Blob Storage, and Google Cloud Storage are used to store files, objects, and other data. These services allow users and organizations to store and access their data through the cloud.

### 🌐 Networking

Amazon VPC, Azure Virtual Network, and Google Cloud VPC provide virtual networks for cloud resources. They allow different resources to communicate with each other and help control network connections and access.

### 🔐 Identity and Access Management

AWS IAM, Azure RBAC, and Google Cloud IAM are used to control access to cloud resources. They help administrators decide which users can access resources and what actions they are allowed to perform.

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

In my assessment, **AWS** offers the broadest range of cloud services. It provides many services for computing, storage, networking, databases, security, analytics, artificial intelligence, and other cloud technologies.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it works closely with other Microsoft products and services. Organizations that already use Microsoft technologies can integrate their existing systems with Azure more easily.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

I would choose **Google Cloud** for its strong capabilities in Artificial Intelligence, Machine Learning, and Kubernetes. Google Kubernetes Engine (GKE) provides a managed Kubernetes service, while Google Cloud also provides tools and services for AI and ML workloads.

### 4. What similarities did you observe among the three cloud providers?

I observed that all three cloud providers offer the same basic types of infrastructure services, such as compute, storage, networking, and identity and access management. The main difference is that they use different names, features, and methods for providing these services.

## Conclusion

Based on my assessment, AWS, Microsoft Azure, and Google Cloud provide similar basic infrastructure services even though their service names and features are different. Compute is used to run workloads, storage is used to keep data, networking connects cloud resources, and IAM controls access.

Learning these similarities is useful because a cloud engineer may work with different cloud providers. Understanding the basic purpose of each service makes it easier to learn and work with another cloud platform.
