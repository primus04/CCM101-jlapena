In this lab, I learned that compute resources are an important part of cloud infrastructure. Compute resources provide the processing power needed to run applications and services. I also learned that compute resources cannot work by themselves. Storage, networking, and an operating system are needed to make everything work properly.

The lab also showed me how Linux is used in cloud computing. Linux provides an environment where applications can run and where resources such as CPU, memory, storage, and networking can be managed. I used KillerCoda to practice Linux commands and check system information in a cloud environment.

I also learned why technical documentation is important before building infrastructure. Documentation helps organize the design and explain how each part works. It provides a clear plan before deploying the infrastructure and helps team members understand the system and avoid mistakes.

During this lab, I developed skills in Linux commands, cloud infrastructure, Markdown, Git, GitHub, and basic cloud architecture design. I learned how to check CPU, memory, storage, hostname, and IP address information and document my findings clearly. Creating the CloudNova infrastructure diagram also helped me understand how users, networks, virtual machines, and storage resources connect to each other.
