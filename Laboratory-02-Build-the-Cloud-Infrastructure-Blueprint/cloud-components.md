# ☁️ Infrastructure Components in Linux Environment

> **Exploring the building blocks of cloud computing through the KillerCoda Linux environment.**

---

## 🖥️ 1. Compute Resources

| 📌 Details      | Information                      |
| --------------- | -------------------------------- |
| **Example**     | `CPU – Intel Xeon E312xx, 1 CPU` |
| **Environment** | Ubuntu Linux / KillerCoda        |

### 🎯 Purpose

The **CPU** processes commands, runs applications, and performs calculations in the Linux environment.

### ☁️ Importance in Cloud Computing

Compute resources provide the processing power needed to run applications, services, and virtual machines in the cloud. They can also be **increased or decreased** depending on the workload.

### 🐧 Relation to KillerCoda

In KillerCoda, the Linux environment uses a **CPU** to execute commands and run the Ubuntu operating system.

> 💡 **Key Idea:** Without compute resources, applications and cloud services cannot process tasks.

---

## 💾 2. Storage Resources

| 📌 Details   | Information                          |
| ------------ | ------------------------------------ |
| **Example**  | `Linux file system and disk storage` |
| **Used For** | Files, programs, and system data     |

### 🎯 Purpose

Storage is used to save **operating system files, user files, programs, and other data**.

### ☁️ Importance in Cloud Computing

Cloud storage allows data and applications to be stored and accessed when needed. It also helps provide **data persistence** and supports backups.

### 🐧 Relation to KillerCoda

The KillerCoda Linux environment provides storage where **files, folders, and system data** can be created and managed using Linux commands.

> 💡 **Key Idea:** Storage keeps important data available even after applications finish running.

---

## 🌐 3. Networking Resources

| 📌 Details  | Information                   |
| ----------- | ----------------------------- |
| **Example** | `Network and IP address`      |
| **Purpose** | Communication between systems |

### 🎯 Purpose

Networking allows the Linux environment to communicate with **computers, servers, and the internet**.

### ☁️ Importance in Cloud Computing

Networking connects cloud resources and allows **users and applications to communicate with cloud services**.

### 🐧 Relation to KillerCoda

The Linux environment in KillerCoda uses a **network connection** to communicate with external services and other resources.

> 💡 **Key Idea:** Networking allows different cloud resources and systems to communicate with each other.

---

## 🐧 4. Operating System

| 📌 Details  | Information            |
| ----------- | ---------------------- |
| **Example** | `Ubuntu 24.04.4 LTS`   |
| **Type**    | Linux Operating System |

### 🎯 Purpose

The operating system manages the computer's **hardware** and provides an environment for running applications and commands.

### ☁️ Importance in Cloud Computing

Operating systems provide the platform where cloud applications and services run. They also manage resources such as:

* 🖥️ CPU
* 🧠 Memory
* 💾 Storage
* 🌐 Networking

### 🐧 Relation to KillerCoda

KillerCoda provides an **Ubuntu 24.04.4 LTS Linux environment** where users can practice Linux commands, manage files, and interact with cloud infrastructure.

> 💡 **Key Idea:** The operating system manages the different resources and provides the environment needed to run applications.
