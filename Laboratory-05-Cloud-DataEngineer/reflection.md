# 📝 Checkpoint 6 - Mission Reflection

This laboratory helped me understand cloud storage and how to deploy an object storage server using MinIO and Docker.

Object storage is better for storing millions of photos because it can handle large amounts of data and easily expand as the number of files increases. Unlike traditional block storage, which divides data into blocks, object storage organizes files as objects with unique identifiers and metadata. This makes photos easier to manage and retrieve.

Docker made deploying MinIO easier because it allowed me to run the server inside a container without manually installing every component. Using a single command, I could download the MinIO image, configure the login credentials, and set the required ports. This made the deployment process faster and simpler.

A bucket is a container used to organize and store objects such as photos, videos, and documents. In this activity, I created a bucket named `client-photos` where uploaded files could be stored and managed.

Large enterprise companies protect their data by keeping multiple copies of files on different servers or storage devices. They also use replication, backups, and recovery systems to restore files if a physical server crashes. These methods help prevent permanent data loss and keep important files available.

Lastly, my confidence in navigating the Linux command line is growing as I practice running commands, deploying Docker containers, and checking whether services are working properly. Although some commands were unfamiliar at first, I gradually learned how they work and why they are important. This activity helped me improve my technical skills and encouraged me to continue learning about Linux, Docker, and cloud computing for my future career in Information Technology.
