# 📝 Mission Reflection

## 🔐 Laboratory-08: Cloud Security Engineer

Completing this mission helped me understand the importance of protecting cloud servers using firewalls and security rules.

A host-based firewall protects a server even if the physical network perimeter is breached. It provides another layer of security directly on the server by controlling incoming and outgoing traffic. This helps prevent unauthorized connections even when other network security systems fail.

Managing open network ports is important because every open port can become a possible entry point for attackers. By allowing only the necessary ports, we can reduce the attack surface and make the server more secure. During this activity, I learned how to allow SSH and port 8080 while blocking other incoming connections using UFW.

In a real enterprise environment, leaving a database port like 3306 for MySQL open to the public internet is dangerous because attackers can attempt brute-force attacks, exploit vulnerabilities, or access sensitive information. Database servers should only accept connections from trusted applications or authorized administrators.

Completing this mission changed my perspective on server security. I realized that even a simple server running a web application can become vulnerable if its ports and firewall rules are not properly configured. Security requires careful planning, regular monitoring, and continuous improvement.

## 🎯 Key Takeaway
Security is not a one-time task. It is a continuous responsibility that requires proper configuration, monitoring, and protection against possible threats.
