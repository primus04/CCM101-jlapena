# 🔐 Security Audit Report

## 📚 Checkpoint 2 - Research: Security Best Practices

### 🔑 1. Principle of Least Privilege (PoLP)
The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. This is important in cloud user accounts because it prevents unauthorized access and reduces the risk of accidental or malicious changes to the system.

### 🎯 2. Attack Surface
The attack surface refers to all the possible entry points that attackers can use to access or exploit a virtual machine. This includes open ports, running services, applications, and user accounts. Reducing the attack surface makes the virtual machine more secure.

### 🚫 3. Default Deny Policy
A Default Deny Policy means blocking all incoming or outgoing traffic unless it is explicitly allowed. It is safer because it prevents unknown or unauthorized connections instead of trying to block individual hackers one by one. This approach provides stronger protection against unexpected threats.

### 🛡️ Security Summary
Following these security practices helps protect cloud systems, prevent unauthorized access, and reduce security risks.
